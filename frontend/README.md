# CivicSetu

CivicSetu is a citizen complaint and redressal portal that enables citizens to report civic issues in their local areas, including road damage, water supply problems, garbage collection, streetlights, and drainage. Citizens can mark issue locations, explore public reports, and track the status of their complaints through a simple, accessible interface.

The platform follows a clean, light, government-portal-inspired design and supports both English and Hindi.

## Features

- Report civic issues with detailed descriptions and location information.
- Explore public reports with search, category and status filters, and pagination.
- Citizen dashboard to view and track personal complaints.
- Leaderboard recognising active citizens and their contributions.
- Secure user login and registration.
- Bilingual interface with English and हिन्दी support.
- Responsive design for desktop, tablet, and mobile devices.
- Keyboard-accessible focus styles and reduced-motion support for a more inclusive experience.

## Tech Stack

- **Frontend:** React with Vite
- **Routing:** React Router
- **Icons:** lucide-react
- **Styling:** Plain CSS with a dedicated stylesheet for each page
- **Fonts:** Google Fonts — Noto Sans, Noto Serif, and Noto Sans Devanagari

## Getting Started

### Prerequisites

- Node.js 18 or newer
- CivicSetu backend API running locally (default: `http://localhost:5000`)

### Installation and Setup

1. Clone the repository and navigate to the frontend project directory.
2. Install the required dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in your terminal, usually `http://localhost:5173`.

Make sure the CivicSetu backend API is running before using features that require server communication.
