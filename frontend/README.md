# CivicSetu

A citizen complaint and redressal portal that allows citizens to report civic issues in their area, including roads, water supply, garbage, streetlights, and drainage. Citizens can mark locations, browse public reports, and track the status of their complaints.

The interface follows a light, government-portal style design with a Hindi/English language switch.

## Features

- Report civic issues with details and location.
- Explore public reports with search, category and status filters, and pagination.
- Citizen dashboard to track personal complaints.
- Leaderboard recognising active citizens.
- Login and registration.
- Bilingual interface (English and हिन्दी).
- Responsive layout, keyboard-friendly focus styles, and reduced-motion support.

## Tech Stack

- React with Vite
- React Router for routing
- lucide-react for icons
- Plain CSS with one scoped stylesheet per page
- Google Fonts: Noto Sans, Noto Serif, and Noto Sans Devanagari

## Getting Started

### Prerequisites

- Node.js 18 or newer
- CivicSetu backend API running (default: `http://localhost:5000`)

### Install and Run

```bash
npm install
npm run dev
```

Open the address Vite prints in the terminal, usually `http://localhost:5173`.
